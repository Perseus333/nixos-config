# Xiao Setup Imperative Steps

This is a guide to set up the Xiao machine. assuming that you start from the IONOS VPS pannel and that you have an account and everything.
This script assumes a VPS with just 10GB storage and 1GB RAM hence the generous swap usag This setup assumes a VPS with just 10GB storage and 1GB RAM hence the generous swap usage.

Note: Steps that begin with C are to be run locally, and those with S in the server (Xiao)

1. C: Reinstall the image of the Server (Ubuntu latest version works fine)

2. C: Run ssh-copy-id root@XIAO_IP (with the password generated by IONOS)

3. C: SSH into Xiao, and edit /etc/ssh/sshd_config so that line 78 is uncommented, and reads "PasswordAuthentication no"

4. S: Reserve enough space for swap:
```sh
dd if=/dev/zero of=/swapfile bs=1M count=1536
chmod 600 /swapfile
mkswap /swapfile
swapon /swapfile
free -h
```

5. S: Run [nixos-infect](https://github.com/elitak/nixos-infect):
```sh
curl https://raw.githubusercontent.com/elitak/nixos-infect/master/nixos-infect | NO_REBOOT=1 bash 2>&1
```

6. S: If enountering issues with out of space, unmount `/tmp`, and then the nixos-infect again:
```sh
umount -l /tmp
```

7. S: Reboot and SSH in again. You should be inside NixOS this time.

8. S: Remove the `/old-root` file that nixos-infect left behind. It just contains the files of the previous OS.

```sh
rm -r /old-root
```

9. S: Create the directory where the key will be stored.
```sh
mkdir -p /var/lib/sops-nix
```

10. C: Copy the keys and the nixos config to the machine.

```sh
rsync -aAxv DIR/key.txt root@XIAO_IP:/var/lib/sops-nix/
rsync -aAvx DIR/nixos/   root@XIAO_IP:/etc/nixos/
```

11. S: The swap will have been set to ~400 MB, add 1 GB more for safety:
```sh
fallocate -l 1G /swapfile
chmod 600 /swapfile
mkswap /swapfile
swapon /swapfile
```

12. C: Build the config remotely with `nixos-rebuild`.
```sh
nix run nixpkgs#nixos-rebuild -- switch --flake DIR/nixos#xiao --target-host root@XIAO_IP
```


13. (TO FIX) S: If you encounter issues with the boot partition, format it manually, and then run `nixos-rebuild` again.
```sh
umount -l /boot || true
mkfs.vfat -F 32 /dev/vda15
mount /dev/vda15 /boot
```

14. C: When trying to ssh back remeber that the firewall only allows to ssh via wireguard and not over the internet. So ensure that the UDP port used by wireguard is opened in the IONOS firewall.

15. SSH back into xiao, you should be inside!
